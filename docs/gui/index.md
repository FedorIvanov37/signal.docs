# Desktop

## Graphic User Interface

![image](/images/main_window.png)

The Signal GUI provides a user-friendly interface to the Signal library. Since v0.15, it has been available as an .exe 
file, ready to run without installing dependencies. No installation or configuration is required to start the GUI 
on Windows. Run signal.exe to launch Signal.

Open **Tools** → **Settings** to review and change your settings.

The main window lets you view and validate transaction data, generate field values, access transaction processing 
tools, and send and receive transactions.

!!! danger "GUI Restriction"
    Only a Windows x64 build is available. Use the source code to run Signal on another platform. Testing has been 
    performed only on Windows 10/11.
